# GitHub User Finder

**Автор:** [Волкова Ангелина Евгеньевна]

## Описание

Приложение «GitHub User Finder» позволяет искать пользователей GitHub по имени и сохранять избранных в локальный JSON‑файл.

### Функциональность

- Поиск пользователей через GitHub API.
- Отображение результатов в виде списка.
- Добавление пользователей в избранное.
- Сохранение избранных пользователей в JSON‑файл.
- Валидация ввода (проверка на пустое поле).

## Использование API

Приложение использует публичный GitHub API (https://api.github.com/users/{username}) для получения информации о пользователях.

## Как использовать

1. Установите зависимости: `pip install requests`.
2. Запустите приложение: `python app.py`.
3. Введите имя пользователя GitHub в поле поиска.
4. Нажмите кнопку «Найти» для отображения информации.
5. Нажмите «Добавить в избранное», чтобы сохранить пользователя.

## Примеры использования

**Тест 1: Поиск существующего пользователя**

1. Введите `octocat` в поле поиска.
2. Нажмите «Найти».
3. Ожидаемый результат: отображается информация о пользователе `octocat`.

**Тест 2: Поиск несуществующего пользователя**

1. Введите случайный набор символов (например, `asdfghjkl123`).
2. Нажмите «Найти».
3. Ожидаемый результат: появляется сообщение «Пользователь не найден».

**Тест 3: Пустое поле поиска**

1. Оставьте поле поиска пустым.
2. Нажмите «Найти».
3. Ожидаемый результат: появляется сообщение «Поле поиска не должно быть пустым!».

**Тест 4: Добавление в избранное**

1. Найдите любого существующего пользователя.
2. Нажмите «Добавить в избранное».
3. Ожидаемый результат: пользователь появляется в списке избранных.

**Тест 5: Сохранение данных**

1. Добавьте нескольких пользователей в избранное.
2. Закройте приложение.
3. Откройте приложение снова.
4. Ожидаемый результат: список избранных пользователей сохранён.
